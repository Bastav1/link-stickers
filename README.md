# 🔗 Link-Sticker

A modern, minimalist **link-in-bio** web app for creators, developers, and professionals. Share all your important links from one customizable page.

---

## ✨ Features

- 🔐 **User Authentication** (JWT)
- 🧑‍🎨 **Custom Profile**: bio
- ➕ **Link Management**: add, delete links
- 🎨 dark themes (tailwind-based)

---

## 🚀 Tech Stack

| Layer        | Tech Used                  |
|--------------|----------------------------|
| Frontend     | React                      |
| Styling      | Tailwind CSS               |
| Backend      | Express.js                 |
| Database     | MongoDB (Mongoose)         |
| Auth         | JWT                        |

---

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/link-sticker.git
cd link-sticker

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env

# Run the app locally
npm run dev
